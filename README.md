# CSProjectGroup1 – Patient Health Analysis

This repository contains the C# console application for the Final Mini Project.

The program collects basic patient information (first name, last name, height, and weight),
calculates Body Mass Index (BMI), determines the BMI category, and evaluates the blood
pressure category based on systolic and diastolic readings.

## Features
- BMI calculation using height (cm) and weight (kg)
- BMI category classification
- Blood pressure category analysis
- Clean class design using C# OOP principles
- Console-based user interaction

## Files
- **Program.cs** – Handles user input and displays BMI and Blood Pressure reports.
- **Patient.cs** – Contains patient properties and methods for BMI and BP classification.
